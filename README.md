## About the data and license

Job data comes from the public [Level API](https://jobsbylevel.com/developers?utm_source=github&utm_medium=list&utm_campaign=ai-jobs-list) (no key, no scraping). Salaries appear only when the employer published one in the posting; amounts under 500 are shown per hour, others per year.
